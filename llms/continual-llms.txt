# Continual

> Continual was an operational-AI / MLOps platform for the modern data stack, letting
> data teams declaratively build, deploy, and continuously maintain predictive models
> that live inside cloud data warehouses (Snowflake, Databricks, BigQuery) and speak
> SQL/dbt. Founded by Tristan Zajonc and Tyler Kohn; backed by Amplify Partners (seed)
> and a $14.5M Series A (2022). The product is now dormant — the website at
> continual.ai is a parked single-page shell and the docs host redirects to it — but
> the first-party Python CLI + SDK remains published on PyPI. This llms.txt is
> generated by the API Evangelist enrichment pipeline from the catalog record and the
> verifiable public artifacts, not from a provider-published /llms.txt (none exists).
